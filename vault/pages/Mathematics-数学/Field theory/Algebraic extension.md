A [[Field extension]] $L/K$ is **algebraic** if every element of $L$ is algebraic over $K$, that is, a root of a nonzero polynomial with coefficients in $K$. An extension that is not algebraic contains transcendental elements, and is called transcendental.

- Every finite extension is algebraic: if $[L : K] = n$, then $1, \alpha, \ldots, \alpha^n$ are linearly dependent over $K$.
- $\mathbb{C}/\mathbb{R}$ is algebraic, and so are the finite extensions of $\mathbb{Q}$, the algebraic number fields.
- $\mathbb{R}/\mathbb{Q}$ is not, since $\pi$ is transcendental.

Each algebraic element $\alpha$ has a [[Minimal polynomial]], whose degree is $[K(\alpha) : K]$.

## Properties

1. If $E/F$ and $F/K$ are algebraic, so is $E/K$.
2. If $E$ and $F$ are algebraic over $K$ inside a common field, so is their compositum $EF$.
3. If $E/F$ is algebraic and $F \subseteq K \subseteq E$, then $E/K$ is algebraic.

With Zorn's lemma, these properties give every field an [[Algebraic closure]]. Whether an algebraic extension is [[Normal extension|normal]] or [[Separable extension|separable]] depends on how the minimal polynomials of its elements split.
